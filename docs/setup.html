Set up in five steps

You need an iPad or iPhone on iOS 17.4 or later with Developer Mode turned on. Tick each step as you go; this page remembers where you are.

0 of 5 done
  1. Download the IPAFrom the Releases page. It's unsigned.
    Download
  2. Sideload itWith SideStore or AltStore.
    SideStoreAltStore
  3. Raise the memory limitInstall GetMoreRam and use it on EspressU. Without a higher limit, most games run out of memory.
    GetMoreRam
  4. Set up JITIn Settings, JIT: import your pairing file and connect LocalDevVPN. JIT starts on its own when you launch a game.
  5. Add your gamesFrom the library with the Add button.

If something goes wrong

A game closes on its own

Most games run out of memory unless the limit is raised. Do step 3 (GetMoreRam) and try again.

A game is very slow

JIT is probably off. Without JIT the slower interpreter runs. Check step 4 and that LocalDevVPN is connected.

The game won't open

Encrypted games need your own keys.txt. Games can also be .wua files or decrypted folders.

Still stuck? Ask in the community and say which step you reached.
